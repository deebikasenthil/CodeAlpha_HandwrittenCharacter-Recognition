# Handwritten Digit Recognition using CNN

## Project Overview
This project uses a Convolutional Neural Network (CNN) to recognize handwritten digits from 0 to 9 using the MNIST dataset.

## Technologies Used
- Python
- TensorFlow and Keras
- NumPy
- Matplotlib
- Google Colab

## Model Architecture
- Convolutional layers
- Max Pooling layers
- Flatten layer
- Dense layer
- Dropout layer
- Softmax output layer

## Dataset
The project uses the MNIST dataset containing handwritten digit images.

## Model Performance
- Test Accuracy: **99.16%**
- Test Loss: **0.0257**

## Project Files
- `handwritten_digit_recognition.ipynb` — Complete source code and results.
- `handwritten_digit_cnn.keras` — Saved trained CNN model.

## How to Run
Open the notebook using Google Colab and run the cells in sequence.
